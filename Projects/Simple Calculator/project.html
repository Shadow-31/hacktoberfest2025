Password Generator using Python

🔐 Password Generator Project

This project allows users to generate strong and secure passwords using Python. It combines uppercase, lowercase, numbers, and special characters to create passwords that are both random and hard to guess.

📋 Features:

  • Random password generation using Python
  • Customizable length and character types
  • Beginner-friendly implementation
  • Great for learning Python basics
